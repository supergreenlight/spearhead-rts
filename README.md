# SPEARHEAD — official site

Static one-page site for **SPEARHEAD**, a WW2 Eastern Front RTS by Green Light Studio.

Live: <https://supergreenlight.github.io/spearhead-rts/>

- `index.html` — the whole page. No build step, no dependencies, no external fonts or scripts.
- `assets/` — hero, wordmark, Open Graph image, trailer poster, screenshots (thumb + full).
- `press/SPEARHEAD_PressKit.html` — self-contained press kit (images embedded).
- `robots.txt`, `sitemap.xml` — indexing.
